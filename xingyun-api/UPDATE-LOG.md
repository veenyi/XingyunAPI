## v0.1.0 (2026-08-09)
- 首版：京东 JoyCode 模型在线服务平台（独立于沧云API，仅保留 JoyCode 相关能力）
- 基于 JoyCode2Api 代理：OpenAI / Anthropic 兼容接口，端口 34891
- 功能：在线聊天（问答/编程双模式、联网搜索、深度思考、历史持久化）、账号管理（扫码/OAuth/一键导入、无数量限制）、积分用量（已用/剩余实时显示）、API Token 分发
- 安装向导设置面板密码，安装完成弹窗显示
